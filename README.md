# BALAM — Gestor de Contraseñas

**Grupo 11 | Proyecto Scrum**

BALAM es un gestor de contraseñas desarrollado en C++ como proyecto académico para la asignatura de Tecnología de la Productividad.

El objetivo es crear una aplicación de consola que permita gestionar contraseñas mediante una contraseña maestra, almacenar entradas cifradas y consultar los datos guardados.

El proyecto se desarrollará durante **3 semanas utilizando la metodología Scrum**, con entregas incrementales y una revisión al finalizar cada sprint.

## Tecnologías

- **Entorno de desarrollo:** Visual Studio 2022
- **Control de versiones:** Git y GitHub
- **Interfaz:** Consola
- **Gestión del proyecto:** Scrum y Excel

## Funcionalidades previstas

1. Menú interactivo.
2. Creación de contraseña maestra.
3. Añadir entradas con servicio, usuario y contraseña.
4. Almacenamiento cifrado de contraseñas.
5. Visualización de entradas guardadas.
6. Búsqueda de contraseñas por servicio.
7. Modificación de entradas.
8. Eliminación de entradas.
9. Generación de contraseñas aleatorias.
10. Validación de datos y gestión de errores.

La implementación se realizará progresivamente según las prioridades del Product Backlog.

## Planificación Scrum

### Sprint 1 — Preparación y funcionalidades básicas

**Objetivo:** preparar el entorno de desarrollo y crear una primera versión funcional de BALAM.

- Definir las herramientas de desarrollo.
- Preparar la estructura del proyecto.
- Crear el menú principal.
- Implementar la creación de la contraseña maestra.
- Implementar la verificación de la contraseña maestra.
- Realizar las primeras pruebas.

### Sprint 2 — Almacenamiento de contraseñas

**Objetivo:** incorporar la gestión de entradas y su almacenamiento protegido.

- Añadir entradas de contraseñas.
- Implementar el cifrado y almacenamiento.
- Recuperar y visualizar entradas guardadas.
- Realizar pruebas de funcionamiento.

### Sprint 3 — Mejoras y versión final

**Objetivo:** completar las funcionalidades pendientes y preparar el producto final.

- Buscar, modificar y eliminar entradas.
- Generar contraseñas aleatorias.
- Mejorar las validaciones y el control de errores.
- Corregir incidencias detectadas.
- Realizar las pruebas finales y preparar la demostración.

## Definition of Done

Una funcionalidad se considerará terminada cuando:

1. Funcione correctamente y pueda demostrarse.
2. Cumpla los criterios de aceptación de su historia de usuario.
3. Haya sido probada por otro integrante del equipo.
4. No presente errores críticos conocidos.
5. El código esté guardado y su estado actualizado en el Excel de seguimiento.

## Seguimiento del proyecto

El equipo utilizará un Excel de Scrum para registrar:

- Product Backlog y prioridades.
- Tareas y responsables.
- Horas estimadas y reales.
- Estado de las tareas.
- Gráficos Burndown.
- Problemas detectados y mejoras acordadas.

Al finalizar cada sprint se realizará una revisión del trabajo y una retrospectiva.

## Seguridad

BALAM es un proyecto educativo. Está previsto utilizar una biblioteca criptográfica reconocida para proteger las entradas almacenadas. No se utilizarán contraseñas reales durante las pruebas.
